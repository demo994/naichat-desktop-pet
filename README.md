# 奶龙 → 奶猫 桌宠

双击 `启动桌宠.bat` 运行（需本机 Python 3 + tkinter，已确认有）。

## 玩法
- 它会每隔几秒盯上你的鼠标：先蹲下扭屁股蓄力，再扑过去——追到就是一套连招：啊呜连咬（光标会抖）→ 双手抓住 → 把你鼠标拖到别的位置（拖不动会气鼓鼓放弃）。力度很轻，纯娱乐。
- 三种成长形态：奶龙宝宝 → 少年奶龙（长背刺）→ 奶猫（带一点恐龙尾巴的奶油色猫）。
- 进化条件：累计在线时长 + 成长进度都达标才进化（喂食/学习/打工都涨进度，喂得够多可以跳过时长要求）。

## 养成为核心：生存数值 + 学习 + 打工 + 商店
它现在是一个自食其力的小家伙，你要照顾并培养它：
- **饱腹度 / 水分**：两条会随时间下降的生存条。饿了要吃饭、渴了要喝水；饿渴过度会难过、没力气学习打工，也不追鼠标。
- **金币 🪙**：初始 50。买东西要花钱，钱靠打工赚。
- **三属性**：智力 / 魅力 / 力量，各自有等级（Lv.）。等级决定能解锁哪些工作。
- **学习成长**（菜单「学习成长」）：读书涨智力、唱歌涨魅力、健身涨力量。每次约 9 秒，消耗饱腹/水分，涨属性点和成长进度，够经验就升级并冒金光。
- **打工赚钱**（菜单「打工赚钱」）：9 种工作，低级的无门槛（发传单 15 金、洗碗 18 金、烤肠 22 金），高级的要属性达标才点亮——家教需智力 Lv.3、搬运工需力量 Lv.3、驻唱歌手需魅力 Lv.5、健身教练需力量 Lv.6、程序员需智力 Lv.7、带货主播需魅力 Lv.8。上班时头顶显示工牌图标和进度条，做完结算金币（属性越高出活越多）。
- **商店购物**（菜单「商店购物」）：奶猫小卖部，金币不足按钮自动置灰。四类货：
  - 食物（涨饱腹）：清江鱼、小鱼干、奶油蛋糕、红烧泡面
  - 饮料（涨水分）：矿泉水、珍珠奶茶、冰美式、快乐水
  - 属性道具（直接+1级）：《十万个为什么》→智力、限量口红→魅力、小哑铃→力量
  - 买了就地吃掉/用起来，会说话、冒表情、涨心情。
- 头顶会冒气泡说话，说出当前心情（饿了要清江鱼、渴了要快乐水、上班搬砖、抓到鼠标、被撸开心等）。
- 严肃分区台词系统：它会说的话按情境分成 70+ 个专属语料池（被摸、被吵醒、追鼠标、扑红点、吃东西、打工、猜拳、自娱自乐……），只有对应情境才会说对应的台词，绝不串台；同一情境每次随机换说法、不会连着两句一样。菜单指令的回应也改成日常口吻（比如"好嘞，到时候我会提醒你喝水"而不是"会提醒你喝水"）。例外是几句签名台词保持一字不差："好吧，清江鱼不和我玩，那我自己玩"、"太好了，清江鱼愿意和我玩了"、"清江鱼累了吗？那休息吧"。
- 16 种表情：普通、开心眯眯眼、爱心眼、惊讶、难过、得意（单眼眨眼+坏笑）、生气（X 眼+倒竖眉）、头晕（转圈星星）、困倦、吃东西陶醉（眯眯眼+吐舌）、害羞（下垂眼+小口）、流汗无语（大眼+汗滴+波浪嘴）、笑出眼泪（眯眯眼+泪珠+大张嘴）、大哭（下弯眼+滚落泪滴）、疑惑（一大一小眼）、星星眼（瞳孔里冒出黄色四角星）。表情由情境严格触发：掏出毛线球或点开激光红点会瞬间冒星星眼，吃喝必出陶醉，猜拳赢了随机得意/大笑、输了随机难过/大哭，追丢/拖不动随机流汗，被吵醒一脸懵。
- 心情值系统：撸猫、玩毛线球、吃喝、学习打工都影响心情；难过时它会提不起劲追你。
- 空闲动作：洗脸舔毛、伸懒腰、左顾右盼、散步、打哈欠（张大嘴+眯眯眼）、躲猫猫（双爪捂眼装看不见，几秒后自己揭秘"Surprise！"）、打喷嚏（"阿…阿…"酝酿后"哈啾！！"原地小蹦），再加上猫味十足的三件套：踩奶（粉肉垫双爪左一下右一下地踩）、母鸡蹲（四脚一缩压扁成一块猫面包）、邀玩姿势（头压低屁股翘高、尾巴激动地竖起来）。被拎起来放下会有落地压扁的弹性动画。用力晃它会头晕眼冒星星（心情 -4）。
- 开心蹦跳与迎接：被连撸到说"最喜欢你啦"、躲猫猫揭秘成功时会原地蹦一下；被撸到开心爆表（心情>85）时会就地给你踩奶；冷落它很久之后你再点鼠标/按 Win 键，它会举起爪爪挥动迎接"你回来啦！"；饿过头时它会爪爪合十讨食（仅奶猫形态）。
- 点歌台 🎤：右键菜单「点歌台」列出歌单里的歌，点一首它就现场开唱——唱歌时随机换一种姿态：握麦侧身唱、双爪举麦摇摆、陶醉仰头长音、举双爪蹦跳，嘴随节奏一开一合、头顶不断冒♪。歌词字幕：在歌单文件夹里放同名 `.lrc` 歌词文件，它就按时间轴一句一句把歌词打在气泡上；没有 lrc 就随机唱"啦啦啦～♪"。放完自动谢幕加心情，点歌台里可随时⏹停止。
- 上传歌曲的地方：歌单文件夹 = 程序同目录的「**奶猫音乐盒**」（菜单里点「📂 打开歌单文件夹（把mp3放进去）」直达）。把你的 mp3/wav 拖进去，重新打开点歌台菜单就能看到。个别内嵌超大封面图的 mp3 Windows 放不出来，它会自动剥掉封面缓存一份干净的再播（原文件不动）。
- 更多小细节：点开激光逗猫棒的瞬间，它会先翘起屁股摆出邀玩姿势再开扑；睡得正香时嘴角会一鼓一鼓地冒出口水泡。
- 自娱自乐：冷落它 45 分钟左右，它大概率会自己找乐子——追自己的尾巴（转久了自己都会晕）、扑蝴蝶（屏幕上真有一只🦋飞来飞去）、自己哼歌（冒出♪）、满地打滚（撞到屏幕边缘会弹回来）、对着镜子摆帅气表情。每项都能涨心情和成长进度；你一回来看它，它就正常活动了。
- 喝水提醒：每小时气泡提醒喝水（菜单可开关）。清晨 7 点前把它拎起来，它有大概率犯困直接接着睡。
- 右键菜单：喂清江鱼（20金）、商店购物、学习成长、打工赚钱、摸摸头、玩毛线球、点歌台、激光逗猫棒、猜拳、过来、翻跟头、别闹、喝水提醒开关、查看状态、跟随模式、干扰拉扯开关、睡觉/唤醒、放大缩小、保存状态、退出。
- 查看状态：形态、金币、饱腹/水分/心情三条进度条、智力/魅力/力量等级、进化进度、累计在线时长。
- 激光逗猫棒：开启后点一下桌面任意处就出现一个红色激光点（它会自己抖、几秒后消失），它会立刻冲过去扑拍红点，拍到加心情。红点窗是穿透的，不影响你正常点击。
- 猜拳小游戏：弹窗出石头/剪刀/布，赢了它得意、输了它难过，都影响心情和成长进度。
- 过来：喊一声它就走到你光标脚下。翻跟头：原地空翻一圈带落地星星，加心情。
- 左键按住可以拎起它，双击撸它会冒爱心（也可能触发"思考"发呆，思考时不会追你）；2 秒内连点 5 次会被惹生气、追着你的光标跑。
- 单击它（不拖动）会弹出/收起实时状态面板：金币、饱腹、水分、心情、三属性等级都在上面自动刷新；点面板本身可最小化。
- 彩蛋：按下键盘 Win 键（开始键）或在别处点一下鼠标左键，它会说"清江鱼累了吗？那休息吧"（约 3~5 秒冷却；点它自己身上不算，激光逗猫棒模式和睡觉时不触发）。
- 别闹命令：菜单点「别闹（不追鼠标）」，它会委屈地说"好吧，清江鱼不和我玩，那我自己玩"，然后专心自己玩（散步/舔毛/发呆），不再追你鼠标、连戳它也不反击；再点「别闹中：点我恢复」，它会开心说"太好了，清江鱼愿意和我玩了"，恢复追鼠标。

## 文件
- `pet.py` 全部逻辑（约 2000 行，tkinter + ctypes，无第三方依赖）
- `pet_state.json` 自动存档：形态、成长进度、在线时长、饱腹、水分、心情、金币、三属性（每 20 秒自动保存，菜单可手动保存）

## 说明
- 拉扯光标用的是 Win32 `SetCursorPos`，每次只挪 7~15 像素、持续 2 秒左右就松口。
- 移动了文件夹后旧存档不会跟过去，进度以 `pet.py` 同目录的 `pet_state.json` 为准。
