# 奶龙 → 奶猫 桌宠

双击 `启动桌宠.bat` 运行（需本机 Python 3 + tkinter，已确认有）。

## 玩法
- 它会每隔几秒盯上你的鼠标：先蹲下扭屁股蓄力，再扑过去——追到就是一套连招：啊呜连咬（光标会抖）→ 双手抓住 → 把你鼠标拖到别的位置（拖不动会气鼓鼓放弃）。力度很轻，纯娱乐。
- 三种成长形态：奶龙宝宝 → 少年奶龙（长背刺）→ 奶猫（带一点恐龙尾巴的奶油色猫）。
- 进化条件：累计在线时长 + 喂食进度都达标才进化（喂得够多可以跳过时长要求）。
- 头顶会冒气泡说话，说出当前心情（饿了要清江鱼、抓到鼠标、被撸开心等）。
- 9 种表情：普通、开心眯眯眼、爱心眼、惊讶、难过、得意（单眼眨眼+坏笑）、生气（X 眼+倒竖眉）、头晕（转圈星星）、困倦。表情由心情系统自动切换：饿过头或心情低落会难过，摸多了会冒爱心，拉扯成功会得意。
- 心情值系统：撸猫、玩毛线球、喂鱼涨心情，长时间不理会掉心情；难过时它会提不起劲追你。
- 空闲动作：洗脸舔毛、伸懒腰、左顾右盼、散步；被拎起来放下会有落地压扁的弹性动画。用力晃它会头晕眼冒星星（心情 -4）。
- 喝水提醒：每小时气泡提醒喝水（菜单可开关）。清晨 7 点前把它拎起来，它有大概率犯困直接接着睡。
- 右键菜单：喂清江鱼、摸摸头、玩毛线球（它会追着拍）、喝水提醒开关、查看状态（形态/饥饿/心情/进化进度/累计在线）、跟随模式开关、干扰拉扯开关（嫌烦就关）、睡觉/唤醒、放大缩小、保存状态、退出。
- 左键按住可以拎起它，双击撸它会冒爱心（也可能触发"思考"发呆，思考时不会追你）。

## 文件
- `pet.py` 全部逻辑（约 1000 行，tkinter + ctypes，无第三方依赖）
- `pet_state.json` 自动存档：形态、喂食进度、在线时长、饥饿值、心情值（菜单里可手动保存，也会每 20 秒自动保存）

## 说明
- 拉扯光标用的是 Win32 `SetCursorPos`，每次只挪 7~15 像素、持续 2 秒左右就松口。
- 移动了文件夹后旧存档不会跟过去，进度以 `pet.py` 同目录的 `pet_state.json` 为准。
